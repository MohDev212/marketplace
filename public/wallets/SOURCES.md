# Wallet artwork

`controller.svg` is the unmodified SVG decoded from the icon exported by
`@cartridge/controller` 0.13.9 (`src/icon.ts`). It preserves the existing wallet
choice artwork while the connector implementation is loaded on demand.
Source: https://github.com/cartridge-gg/controller (packages/controller/src/icon.ts).
